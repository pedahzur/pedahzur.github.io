Seven principles

These rules recur in every method on this site. Each one was written after something went wrong.

1Prepares, never approves

The assistant drafts, checks and proposes. Approval stays with the researcher, one batch at a time. A suggestion that was accepted or rejected is logged with the reason.

Where you see it: Will this draft survive a hostile referee?

2A false match is worse than no match

When a citation cannot be matched to the library record, it stays unmatched and is flagged. A wrong match looks like verification and hides the gap.

Where you see it: Start here, rule 2 of the rules file

3Co-presence is a hypothesis, not a fact

Two names in the same document suggest a link worth checking. They do not establish a relationship. A person decides each doubtful case.

Where you see it: historical-entity-tracker

4A search that returns little is not evidence of absence

In a large corpus a name may be missing, misspelled or written in another alphabet. An empty result describes the search before it describes the archive.

Where you see it: From Question to Evidence

5A rule nobody checks erodes

A rule written in a guidance file wears away within weeks. A rule that is checked at the moment of writing holds.

Where you see it: Start here

6Quote from the scan, not from the machine text

Text recognition produces machine text. It is good for finding a passage. The quotation is taken from the page image.

Where you see it: From One Report to Two Histories

7Pilot first, then scale

Every large job starts with a small pilot and ends with a spot check of a sample. The pilot is where the method fails cheaply.
